# 13. Romar to integer

## Средне

Для этого нам нужно вспомнить что такое связные списки. Когда каждый элемент массива указывает на следующий элемент в массиве.

Теперь к заданию. нам нужно сложить два числа:

```
342 + 465 = 807
```

В связном массиве числа будут расположены от меньшего разряда к старшему:

```
2->4->3 + 5->6->4 = 7->0->8
```

Теперь нам нужно вспомнить правила сложения столбиком:
- Складываются числа одинаковой разрядности.
- Если сумма разрядов больше 10, добавляем % 10 к следующему разряду.
- Если у числа нету своей пары разрядности, число остается без изменений.

Теперь у нас есть все необходимое, чтобы решить эту задачу.

Идём по обоим спискам одновременно, пока остался хотя бы один из них или есть перенос. На каждом шаге складываем в `total` перенос и значения текущих узлов (у закончившегося списка значения нет, он ничего не добавляет). Последняя цифра суммы `total % 10` становится новым узлом результата, а `total // 10` переходит в перенос для следующего разряда. После окончания результата возвращаем ответ. Задача решена.
