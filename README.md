# LeetCode: решения на разных языках

Репозиторий для изучения возможностей разных языков программирования
на примере задач LeetCode. Одна задача решается на нескольких языках,
чтобы сравнить синтаксис, стандартные библиотеки и подходы.

**Мой профиль LeetCode:** [cameon8868](https://leetcode.com/u/cameon8868/)

## Как устроена папка с задачей

Каждая задача лежит в папке `номер-НазваниеЗадачи` и содержит:

- `README.md` с условием, идеей решения и оценкой сложности
- файлы решений на разных языках
