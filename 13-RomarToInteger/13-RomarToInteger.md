# 13. Romar to integer

## Легко

Нам даны `s`-римские символы,
нужно вернуть: `s` - числа. 

---

**Есть некоторые правила в римской системе:**

**№1 Правило - сами обозначения этих символов.**

|Symbol|Value|
|---|---|
|I|1|
|V|5|
|X|10|
|L|50|
|C|100|
|D|500|
|M|1000|

**№2 Правило - Вычитание и использование.**

Если следующая цифра больше предыдущей - складываем, если меньше - вычитаем.

**№3 Правило - Повторение букв**

Никогда нельзя ставить одну и ту же букву более трех разов подряд

**№4 Правило - римские символы больше 4000**

Так как мы не можем написать ММММ, мы пишем горизонтальную линиюю над символом, что означает, что число будет умножено на 1000.

Пример:

    _V = 5000

можно разрешить два символа, которые вычитают из одного и того же числапока они не вместе.

Пример:

    CMIX (900 + 9) = 909

---

**Как решать?**

Ограничения:

    1 <= s.length <= 15
    s состоит только из символов 'I', 'V', 'X', 'L', 'C', 'D', 'M'.
    Гарантируется, что s — корректное римское число в диапазоне [1, 3999].

Так как число меньше 4000, правило №4 нам не нужно, а корректность строки гарантирована, поэтому проверять повторения не требуется.

**Идея:** идём слева направо. Если значение текущего символа меньше
значения следующего, оно вычитается, иначе прибавляется.

**Решение**

1. Заводим `res = 0`.
2. Проходим по строке `s`.
3. Для каждого символа берём его значение (правило №1).
4. Если есть следующий символ и `текущий < следующий` — `res -= текущий`, иначе `res += текущий`.
5. Возвращаем `res`.

**Сложность:** O(n) по времени, O(1) по памяти.

# Code


```cpp
#include <vector>
#include <map>
#include <string>

using namespace std;

class Solution {
public:
    int romanToInt(string s) {
        vector<int> numList;
        //the designations of these symbols themselves. (rule 1)
        map<char, int> rule1;
        rule1['I'] = 1;
        rule1['V'] = 5;
        rule1['X'] = 10;
        rule1['L'] = 50;
        rule1['C'] = 100;
        rule1['D'] = 500;
        rule1['M'] = 1000;

        for(int i=0;i < s.size();i++){
            numList.push_back(rule1[s[i]]);
        }
        int res = 0;

        for(int i=0; i < numList.size();i++){

            if(i + 1 < (int)numList.size() &&  numList[i] < numList[i+1]){
                res -= numList[i];
            }else{
                res += numList[i];
            }
        }
        return res;
    }
};
```
