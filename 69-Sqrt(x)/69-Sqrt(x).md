# 69. Sqrt(x)

## Легко

По условию, нужно узнать корень `x`, не используя встроенные функции, такие как `sqrt(x) in с++` или `x**n in python`.

## Как решать??

Для решения нужно вспомнить, что такое корень. Определение, что это возведение в `0.5`. В математике это `y = (x)^0.5`. Дальше по формулу Ньютона:
```
y_{n+1} = y_n − f(y_n) / f'(y_n)

f(y) = y² − x

f'(y) = 2y

y_{n+1} = y_n − (y_n² − x) / (2y_n)
        = (2y_n² − y_n² + x) / (2y_n)
        = (y_n² + x) / (2y_n)
        = (y_n + x / y_n) / 2
```

Создаем функцию и упрощаем это до `guess=x` `guess = (guess + x / guess) / 2` (java), чем больше итераций, тем точнее число.
